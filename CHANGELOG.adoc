== Unreleased

=== Added

* Add `-seed` and `-colors` options for reproducible palettes. The color of
  each block is derived from the seed and its grid position, so the PNG and
  SVG outputs match block by block regardless of concurrency

=== Changed

* Validate the dimensions, the block size and the palette before generating,
  and limit the number of blocks and the number of goroutines
* Clip the edge blocks of the SVG output to the canvas so that they match
  the PNG output
